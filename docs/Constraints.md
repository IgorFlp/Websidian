# Constraints
- Websidian is a project made for old hardware reusability in localhost enviroments, ALL architectural and styling decisions NEED to be visible in old devices like "Android 4" with old browser versions.
- All pages are designed as "touch first" for better UX on old Android Tablets.
- Never add libraries! only use native, old compatible crude HTML, CSS and JS.
- NEVER use complex CSS new features
- For API calls ALWAYS use XMLHttpRequest, never Axios or Fetch.
